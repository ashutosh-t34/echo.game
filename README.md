🎮 ECHO – A Time Memory Game

ECHO is a small browser-based game built using HTML, CSS, and JavaScript.
The core idea of the game is simple but unique:

Your past actions return as enemies.

You must think before you move, because what you do now can hurt you later.

🧠 Game Concept

You control a square.

Every few seconds, an echo appears.

An echo repeats your past movements.

If an echo touches you → Game Over.

Reach the 🏁 flag to level up and increase your score.

This game focuses on planning, memory, and timing, not fast reflexes.

🎮 Controls
Keyboard

Arrow Keys (← ↑ → ↓) → Move

Any key at start → Begin the game

Mobile

Tap on the screen to move (basic support)

🏁 Objective

Avoid touching any echo.

Reach the goal flag 🏁.

Each level increases difficulty.

Try to achieve the highest score.

✨ Features

Clean start screen (“Press any key to begin”)

Unique time-echo mechanic

Level and score system

FAQ panel for new players

Vibrant, modern UI

Keyboard and mobile friendly

No external libraries (pure HTML/CSS/JS)
